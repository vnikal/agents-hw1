# ДЗ 1 · Вариант А

Леонова Вероника. Факультатив «Создание ИИ-агентов с нуля».

## Запуск

Откройте нужный HTML-файл в браузере. Сервер, сборка и подключение к интернету не нужны.

- [tracker-v1.html](tracker-v1.html) — исходный ответ на короткий запрос.
- [tracker-v1-fixed.html](tracker-v1-fixed.html) — первая версия после исправлений.
- [tracker-v2.html](tracker-v2.html) — реализация по спецификации.

Начальный набор для обеих попыток одинаков. В v2 его можно восстановить перезагрузкой. Для v1 и v1-fixed очистите ключ localStorage `study-task-tracker-v1` для страницы трекера перед независимой проверкой, если браузер сохранил предыдущий список. При открытии через `file://` доступность localStorage зависит от браузера.

Две независимые сессии Codex использовали одну и ту же модель по умолчанию. Точное название и версия модели для этих сессий не подтверждены. Вторая попытка использовала спецификацию в формате OpenSpec, без CLI.
