# Данные и расчёты

## Модель

| Поле | Тип | Назначение |
| --- | --- | --- |
| `id` | Строка | Уникальный идентификатор задачи |
| `title` | Строка | Название без пробелов по краям |
| `hours` | Число | От 0,5 до 24 ч включительно, кратно 0,5 ч |
| `done` | Булево | `true` для готовой задачи, `false` для активной |

Начальные данные:

| Название | Часы | `done` |
| --- | ---: | --- |
| Чтение | 2 | `true` |
| Практика | 4 | `false` |
| Повторение | 2 | `false` |

## Изменения и проверка данных

Основное состояние — массив задач. Добавление присваивает уникальный идентификатор и `done = false`. Удаление и переключение статуса находят задачу по идентификатору.

При отправке формы название проверяется после `trim`. Пустые часы проверяются до преобразования в число. Преобразованное значение должно быть конечным, лежать в пределах от 0,5 до 24 включительно и давать целое число при умножении на два. Ошибки показываются рядом с соответствующими полями. При любой ошибке массив и исходный ввод сохраняются.

## Список и прогресс

Выбранный фильтр хранится отдельно от массива. При запуске выбран фильтр «Все». Фильтр «Активные» показывает задачи с `done = false`, а «Готовые» — с `done = true`.

Часы всех задач и часы готовых суммируются по полному массиву. При нулевой сумме процент равен 0. В остальных случаях процент — результат округления `100 × часы готовых / часы всех` до ближайшего целого. Старт даёт 2 из 8 ч и 25%, а отметка «Практики» готовой даёт 6 из 8 ч и 75%.

## Опциональное сохранение

Если добавлено сохранение в `localStorage`, стартовые данные применяются при отсутствии сохранённого списка. Сохранённый пустой массив считается действительным состоянием. При недоступности чтения или записи изменения остаются в памяти текущей страницы, а интерфейс сообщает о работе в памяти. Доступность `localStorage` по `file://` зависит от браузера.
