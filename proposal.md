# Мини-трекер учебных задач

## Цель

Вести учебные задачи на неделю и видеть, сколько запланированных часов уже выполнено.

## Границы

- Один автономный файл `tracker-v2.html` со встроенными CSS и JavaScript, без CDN, сторонних библиотек и внешних API.
- Стартовый список из трёх задач, добавление, удаление, переключение статуса, фильтрация списка и общий прогресс по часам.
- Проверка названия и часов при добавлении с ошибкой рядом с соответствующим полем и сохранением введённых значений.
- Подписанные поля и кнопки, интерфейс без горизонтальной прокрутки при ширине 390 px.
- Хранение в `localStorage` опционально. При его использовании предусмотрены режим в памяти и сообщение о недоступности хранилища. Поддержка `localStorage` при открытии по `file://` зависит от браузера.

Реализация выполняется по отдельному запросу.
